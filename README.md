# Manas Mahajan — AI, Design & Mobility Portfolio

A responsive static portfolio designed for quick deployment on GitHub Pages.

## Files
- `index.html` — page structure and project content
- `style.css` — design system, responsive layouts and animations
- `script.js` — interactive EV range concept and project detail modals

## Before submitting
1. Open `index.html` locally and test it in a browser.
2. Confirm the SynapseOS and FlowMind descriptions accurately reflect your actual implementation.
3. Add your email or resume link if you want them shown.
4. The mobility experience is explicitly a concept study, not an official Ather product or partnership.
5. Verify your GitHub and LinkedIn links.

## Deploy using GitHub Pages
1. Create a new public repository on GitHub, for example `manas-ather-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (not inside another nested folder).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear. Open it in an incognito/private tab to confirm it is public.
7. Submit the live URL, not the GitHub repository URL.

The site uses Google Fonts as progressive enhancement; it remains usable if fonts do not load.
